# 工作流

本文件是八阶段流程的权威说明。机器入口见 `docs/manifest.json`，阶段动作见 `docs/prompts/`，检查命令见 `docs/checks.md`。

| 阶段 | 目标 | 写入 |
| --- | --- | --- |
| 01 需求确认 | 固化目标、范围、验收标准 | 需求产物 |
| 02 数据处理 | 按 Skill 生成或更新数据 | 授权数据路径 |
| 03 数据校验 | 校验 Schema、来源和完整性 | 运行记录 |
| 04 前端调整 | 按需更新展示与交互 | 授权前端路径 |
| 05 结构校验 | 检查边界、引用和遗留路径 | 运行记录 |
| 06 测试 | 执行适用测试 | 运行记录 |
| 07 自动修复 | 修复失败项并回跑 03、05、06 | 原失败项授权路径 |
| 08 最终验收 | 汇总证据并给出最终状态 | 验收报告 |

## 循环

1. 01 至 06 顺序执行。
2. 任一校验失败，进入 07；最多自动修复 3 轮。
3. 每轮修复后回跑 03、05、06。
4. 08 仅在全部标准与检查通过时输出 `all_passed`。
5. 3 轮后仍失败，输出 `has_bugs`，任务不得标记完成。

每阶段都必须输出 `AGENT-HANDOFF`，格式见 [templates/handoff.md](templates/handoff.md)。
