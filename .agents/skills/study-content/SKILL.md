# 学习内容

1. 读取 `data/shenlun/route.json` 或 `data/xingce/route.json`。
2. 考试事实以官方大纲为准；机构资料只作为学习方法参考。
3. 保留资料标题、发布者、URL 和访问日期。
4. 更新对应 JSON，不维护第二份内容。
5. 分别使用 `schemas/shenlun-route.schema.json` 或
   `schemas/xingce-route.schema.json` 校验。
6. 执行 `npm run check`。

禁止把机构经验写成官方评分规则。
