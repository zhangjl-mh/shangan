# 我要上岸

Agent 生产公考备考数据，Next.js 负责展示。

## 核心能力

- 行测、申论学习路线与老师推荐
- 岗位采集与筛选
- 每日时政资讯

## 目录

| 路径 | 职责 |
| --- | --- |
| `.agents/skills/` | 业务 Skill 与专用脚本 |
| `.agents/harness/` | 8 Agent 流水线 |
| `schemas/` | 数据契约 |
| `data/` | 正式业务数据 |
| `app/` | 前端代码 |
| `docs/` | 详细规范 |

## 命令

```bash
npm run dev
npm run check
```

项目规则见 `AGENTS.md`，详细说明见 `docs/README.md`。
